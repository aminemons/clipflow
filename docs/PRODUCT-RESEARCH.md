# ClipFlow product research

Research checked 19 September 2026 against official product, pricing, and API pages. Prices and limits below are observations of those pages, not promises for ClipFlow; they change by region, billing cycle, and account.

## Product fit and competitive baseline

| Product | Officially documented capabilities relevant to ClipFlow | Free/paid boundary observed | What ClipFlow should learn |
|---|---|---|---|
| [OpusClip](https://www.opus.pro/pricing) | Long-video clipping, AI reframe, animated captions, filler/silence removal, clip-length selection, multi-ratio exports, bulk/social publishing; its crop page says AI Reframe detects important elements and permits manual framing. | Free plan: 60 credits/month, 1080p, auto reframe and captions, watermark, no editing, exports expire after 3 days. Paid tiers add editing, more ratios, moving-object tracking, bulk/API and scheduling. | Make the first result immediately useful: suggested clips, visible crop preview, and manual timing/framing corrections. Do not promise “viral” scoring in a local MVP.
| [Vizard](https://vizard.ai/pricing) | AI-generated clips, full editor, auto reframe, subtitles/translation, transcript download, social publishing and API. | Free: 60 credits/month, 720p, 3-day storage, 10-minute export limit. Paid Creator/Business add no watermark, 4K, larger storage, scheduling, collaboration; API is included in paid plans and consumes upload minutes ([API pricing](https://docs.vizard.ai/docs/pricing)). | Credits and export limits are easy to explain. ClipFlow can expose local processing as “no account/no usage credits,” with optional provider adapters clearly labeled.
| [Klap](https://klap.app/pricing) | AI clipping, auto-reframe/speaker tracking, captions, analytics and social accounts; official API supports long-video-to-shorts and separate video editing/reframe tasks ([API docs](https://docs.klap.app/)). | Pricing page lists clip quotas by paid plan; official free generator says one video to start, no credit card, no watermark. API is usage based: separate input, generation and export operations ([API pricing](https://docs.klap.app/pricing)). | A fast “analyze → ranked suggestions → edit by transcript/timeline” flow is a strong reference. Keep ranking optional; deterministic scene/silence segmentation is enough for the assessment.
| [Descript](https://www.descript.com/pricing) | Text-based editing, AI co-editor (“Underlord”), Create Clips, filler removal, Studio Sound, captions/transcription, 1080p/4K exports and collaboration. | Free exists for recording/editing/mixing and trying AI tools; paid plans add media hours, AI credits, watermark-free exports, higher resolution and team features. | Use plain language and a transcript/timeline handoff. Do not copy cloud AI assumptions: local FFmpeg/OpenCV should remain the core path.
| [CapCut Auto Reframe](https://www.capcut.com/tools/auto-reframe) / [long video to shorts](https://www.capcut.com/tools/auto-video-editor) | Auto reframe to platform ratios, scene-aware automatic cutting, chosen target duration, captions/templates, preview/edit/export and direct sharing. | CapCut’s help page states Auto Reframe is currently a Pro feature after an earlier free/limited period; region and platform affect availability. | Put target duration and crop controls beside each suggested clip. Treat “free” as an unstable provider claim; local processing avoids that dependency.

Common denominator: these services combine three distinct jobs—finding moments, editing the time range, and re-framing the picture. ClipFlow’s assessment scope can cover all three with open local tools: FFmpeg/ffprobe for media, PySceneDetect plus `silencedetect` for boundaries, and OpenCV/MediaPipe tracking with a smoothed crop path. Add a deterministic center fallback when no subject is detected, and let users override both start/end and framing.

## Higgsfield integration boundary

Higgsfield now documents a separate developer API at [docs.higgsfield.ai](https://docs.higgsfield.ai/docs) and [its API overview](https://www.higgsfield.company/creator-hub/help-center/integrations/what-is-the-higgsfield-api). The API is an authenticated, asynchronous generation API: submit to a model endpoint, then poll a status URL or receive a webhook. Inputs may be uploaded to Higgsfield storage; completed outputs are retained for at least seven days, so an adapter should download results to local storage promptly.

The API is for generative images/video models, not a documented replacement for ClipFlow’s local clip segmentation, subject tracking, trim/extend controls, or H.264 export. The official catalog and website plan are separate products. API use requires its own key and a prepaid US-dollar balance; the help page says minimum top-up is $5, video billing is generally per output second, and API rates vary by model/configuration. The website subscription credits do not authorize API calls. Do not hard-code current model names or rates.

Recommended architecture: define an optional `HiggsfieldAdapter` behind an interface such as `generate_asset(input, options) -> job`; keep it disabled unless `HIGGSFIELD_API_KEY` is present; submit jobs server-side so the secret never reaches the browser; poll/webhook and persist only downloaded outputs; surface cost and failure states. The adapter can be used later for optional generated B-roll, thumbnails, or creative variants. It must never be required for the assessment’s core flow, and the README/demo must work with no Higgsfield account, network access, or paid credits. Do not claim Higgsfield performs subject tracking or reframe unless a specific current model endpoint and input contract are verified.

The API docs show Python/TypeScript SDKs or direct HTTP, `Authorization: Key <id>:<secret>`, request IDs, status/cancel URLs, and webhooks. Treat the API key as a server-only secret and download output before the provider’s retention window ends. For a 48-hour assessment, a disabled adapter stub plus documented boundary is safer than making the local product dependent on a paid generation service.

## Tiering recommendation for ClipFlow

**Free local core (the assessment deliverable).** Upload a local 16:9 file; optionally ingest a YouTube URL through `yt-dlp`; detect scenes and silence; suggest complete, non-overlapping ranges; manually add/delete/extend/shorten clips; preview a 9:16 crop; track the largest/persistent face or salient subject with smoothing; render MP4 with original audio; export one or ZIP. No login, provider account, watermark, usage meter, or proprietary API.

**Optional local upgrades.** Higher-resolution render, stronger detector/model, transcript-driven search, captions, and alternate ratios can be feature flags or installed extras. Explain CPU/GPU and disk requirements rather than calling them paid tiers.

**Provider adapters (future/paid).** Cloud virality ranking, animated caption styles, social scheduling, collaboration, analytics, API batch processing, generative B-roll, and Higgsfield generation belong behind explicit adapters and credentials. A provider outage must leave local import, editing, tracking, and export usable.

## README/source attribution guidance

Link to the official pages above in a short “Product research / inspiration” section. Say that competitor capabilities and pricing were checked on 2026-09-19 and can change. Attribute implementation choices to open-source tools separately (FFmpeg, PySceneDetect, OpenCV/MediaPipe, yt-dlp) and include their licenses in the repository’s dependency notice. Do not present competitor feature names, prices, or “free” limits as ClipFlow commitments. State clearly that Higgsfield is optional and that the assessment can be completed without an account or paid service.
